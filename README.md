# Sales Analytics Dashboard using SQL & Power BI

## Project Overview

This project focuses on analyzing sales data using SQL and creating an interactive dashboard in Power BI to generate meaningful business insights. The goal is to transform raw sales data into actionable information that supports data-driven decision-making.

---

## Objectives

- Clean and prepare sales data using SQL
- Perform exploratory data analysis
- Identify sales trends and business patterns
- Create an interactive Power BI dashboard
- Present insights through visualizations

---

## Tools & Technologies

- SQL
- PostgreSQL
- Power BI
- Data Analysis
- Data Visualization
